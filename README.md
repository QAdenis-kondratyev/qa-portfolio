## 🧭 Testing Approach

1. **Test early** — review requirements before code exists; the cheapest bug is the one found in the spec.
2. **Report root causes, not symptoms** — group related findings so developers fix the cause once.
3. **Severity = business impact** — a bug that loses orders outranks a dozen cosmetic issues.
4. **Make results reproducible** — clear steps, evidence, and automated checks that re-detect known defects.
